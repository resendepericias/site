# Resende Perícias Médicas — site público

Site estático (HTML + CSS + JS, sem build) publicado no GitHub Pages em https://resendepericias.com.br.

- Testar: `python3 -m http.server 8766` nesta pasta e abrir http://localhost:8766
- Publicar: `git add -A && git commit -m "mensagem" && git push` (o GitHub Pages atualiza sozinho)
- Domínio: DNS no GoDaddy (A → 185.199.108–111.153; www → resendepericias.github.io). Arquivo `CNAME` não pode ser apagado.
